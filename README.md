# 📦ALOHA Data Converter

This repository provides tools to convert ALOHA HDF5 datasets into multiple robot-learning formats:

- Lerobot format for Hugging Face Lerobot datasets.
- RMB (RoboManipBaselines) format for RoboManipBaselines.
- RLDS package layout for TFDS/RLDS workflows.
- GR00T-compatible layout (Parquet + per-camera MP4 + metadata).
